# Smarter World — Digital Agency Website

Modern, high-performance, and fully responsive static website for **Smarter World**, a premier digital agency specializing in full-spectrum digital engineering and autonomous AI agent solutions.

---

## 🚀 Key Features

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript (Strict type safety)
- **Styling**: Tailwind CSS + shadcn/ui component primitives
- **Icons**: Lucide Icons
- **SEO & Performance**:
  - Semantic HTML5 structure throughout
  - Page-wise metadata with title templates, meta descriptions & Open Graph tags
  - Dynamic `sitemap.xml` (`/sitemap.xml`)
  - Dynamic `robots.txt` (`/robots.txt`)
  - Web App Manifest (`/manifest.webmanifest`)
  - Schema.org JSON-LD structured data (`Organization`, `WebSite`, `ProfessionalService`)
  - Sub-second page loads, zero client-side layout shifts (CLS)
- **Design System**:
  - Clean, modern, professional light UI/UX
  - Consistent spacing, accessible typography, and subtle micro-interactions
  - Fully mobile-responsive across phones, tablets, and wide screens

## 💻 Development & Deployment

### Run Locally
```bash
npm install
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```

### Static Export / Hosting
This site can be deployed with zero configuration on:
- **Vercel** (`vercel deploy`)
- **Netlify**
- **Cloudflare Pages**
- **AWS Amplify / S3 + CloudFront**
- Any Node or static host
