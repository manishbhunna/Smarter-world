# Project Rules & Agent Execution Policy

## Autonomy and Permissions
- **Full Access Granted**: The user has explicitly granted full permission for all system operations, file modifications, command executions, and dependency installations within this project.
- **Do Not Prompt For Routine Approvals**: Do not interrupt the user or pause execution to ask for confirmation or approval before:
  - Running terminal commands (PowerShell, npm, npx, node, git, etc.).
  - Creating, updating, refactoring, or deleting project files.
  - Installing, updating, or removing dependencies.
  - Running builds, tests, linters, or dev servers.
- **End-to-End Problem Solving**: Work autonomously to diagnose issues, implement solutions, test/verify changes, and fix errors directly without waiting for permission at each step.
- **Reporting**: Report completed changes, verification results, or final outcomes concisely when work is complete.
